Task cards: draw to exact difficulty, draft, complete or fail.

`GAME.md` §7–13: use the difficulty column for the current crew size; draw
until the sum is exact; skip a card that would overshoot. Captain takes first,
then clockwise; pass only if at the start of draft there are fewer tasks than
players; all tasks assigned by the end. Owner-only; complete when permanently
true; fail the mission when any required task is impossible. Replace
objectively impossible combinations; bad player assignment is not a free
redeal.

Acceptance: typed task model covering the families in `GAME.md` §12. The full
96-card text can land incrementally; do not block the milestone on every
illustration variant. Mission-specific draft variants are flags, not new
scenes (`PRESENTATION.md` §16).
